There's no symbol literally named `I2` in this repo — the `stride` you're asking about lives in **im2col** (`flow/hierarchy/im2col.py`, the patch-extraction used by MERA). Here's what it means.

## `stride` in `getIndeices`

```python
def getIndeices(shape, height, width, stride, dialation, offset):
    outHeight = (H - dialation*(height-1)-1) // stride + 1
    i1 = stride * np.repeat(np.arange(outHeight), outWidth)
    j1 = stride * np.tile(np.arange(outWidth), outHeight)
```

`stride` is the **step (in lattice sites) between the top-left corners of consecutive patches** — exactly like the stride in a CNN/im2col. `i1`/`j1` are the patch *origins*; `i0`/`j0` are the within-patch offsets. So:

- `stride` large relative to the patch extent → **non-overlapping** patches (a tiling).
- `stride` small → overlapping patches.

## How MERA sets it (`mera.py:19-20`)

With `kernelSize = 2`, at coarse-graining scale `no`:

| arg | value | meaning |
|---|---|---|
| `height/width` | `2` | 2×2 patch |
| `dialation` | `kernelSize**no = 2^no` | gap between the sites *inside* a patch |
| `stride` | `kernelSize*(kernelSize**no) = 2^(no+1)` | gap between patches |

Note `stride = 2 × dilation`. A 2×2 dilated patch physically spans `dilation*(2-1)+1 + (dilation-1)`... more simply, its full footprint is `2*dilation` sites, so setting `stride = 2*dilation` makes the patches **tile the lattice without overlap** at every scale:

- `no=0`: stride 2, dilation 1 → adjacent non-overlapping 2×2 blocks (finest scale).
- `no=1`: stride 4, dilation 2 → 2×2 patches built from every-other site, spaced 4 apart.
- `no=2`: stride 8, dilation 4 → and so on, each scale acting on a coarser sublattice.

The two `getIndeices` calls per scale differ only in `offset` (`0` vs `2^no`): the offset shifts the whole patch grid by half a block, which gives MERA its two interleaved passes (disentangler-style vs coarse-graining placement). The final `%H`/`%W` makes the tiling periodic (wraps around the torus).

So in one line: **`stride` = the spacing between coarse-graining blocks; MERA picks it as twice the dilation so each RG scale partitions the lattice into non-overlapping 2×2 super-sites.**
