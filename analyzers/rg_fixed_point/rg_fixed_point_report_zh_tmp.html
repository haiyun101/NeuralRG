L=32 MERA 流的 RG 不动点探针

状态(V3 鲁棒性检查之后)。 原分析的主要结论 —— 即"逆向 KL 流在 T_c 处满足我们的假设,因为 z-标准化输出上的 MSE(f_4, f_5) ≈ 10⁻⁵" —— 已经被 V3 恒等残差检查所推翻: 逆向 KL 的深层 block 各自接近恒等映射(在 N(0, I) 上 f_4、f_5 残差 ≈ 0.02–0.3),所以两个近似恒等的函数在同一探针上自然给出相匹配的输出。 仅靠 z-标准化输出的 MSE 探针在构造上就无法区分"学到的尺度不变不动点映射"与 "优化器把这些 block 留作近似恒等映射"这两种情况。前向 KL 的"深层 MSE ≈ 2" 仍然是真实的功能性不对称(V3 残差在 f_4 上达 2.8–15.4 —— 数值很大, 是非平凡工作)。

V2b 补遗(单槽链式输入)。 V2 的链式输入探针把上一个 block 的整个 4 元素输出作为下一个 block 的 2×2 patch 输入。生产中 MERA 的组合方式只 重用 patch 中 4 个位置里的 1 个(保留粗粒度槽 / kept-coarse slot); 另外 3 个槽是新鲜的 N(0, I)。V2b 修正了这一点:它令 h_s[..., 0, 0] = o_{s+1}[..., 0, 0],并对剩下 3 个 patch 位置重新抽样。 结果:逆向 KL 的 MSE(f_4, f_5) 从 V2 的 0.0000 跳到 V2b 的 1.489, 与非临界温度对照组的值一致。因此原来"逆向 KL 满足我们假设"的读法 是两个叠加的几何错配的产物(V3 的"N(0, I) 上近似恒等"发现, 以及 V2 的"4 元组完整链式"几何)。原始的 V2 和原始的 V4 都没有 经过几何修正这一关。

V4 补遗(数据正向方向,仅保留粗粒度子格点)。 一个补充探针把 真实的 HS 数据通过 MERA 的正向(分析)方向,并在相邻中间场 y_s、y_{s+1} 之间比较慢模子格点(在尺度 s 上跨度为 2^s)。先前一次在完整 L × L y_s 上做平均的版本被撤回 —— 它把慢模与 1 − 1/4^s 个被训练成 N(0, 1) 的冻结潜在位置混在一起,因而所报告的"深尺度上 rev-KL std ≈ 1.1" 实际上是这些冻结潜在位置的"地板效应"。

在保留粗粒度子格点上,V4 的图像更清晰: 逆向 KL 流的慢模 std 单调收缩 3.51 → 0.94,峰度 → 0 (慢模被抹除而不是被粗粒度化),并且在粗格点上发展出反相关的最近邻 (G(1)/G(0) 为负);前向 KL 流则把慢模 std 在中间尺度上吹大到输入的 8 倍 (T_c hs_dataDriven:在 y_3 处 std 从 3.51 → 28.94),之后部分回落。 分块 RG(V5)的"真值"给出 std 3.51 → 2.46 与双峰 kurt ≈ −1.84 —— 两类流都不匹配这条曲线。因此修正后的 V4 一方面确认 V3 (逆向 KL 深层 block 没在做物理上的事),另一方面又增添了两个新病理: 逆向 KL 的慢模塌缩成高斯,以及逆向 KL 的反相关空间结构。

V5 补遗(Wilson–Kadanoff 分块 RG 真值)。 在与 V4 完全相同的 HS 输入上 跑分块平均级联 x_s = AvgPool2d(2)^s(x),并逐尺度与 MERA 子采样的慢模场 进行比较。双轴判决:fwd-KL 把空间结构做对了但幅度搞错了 (在 coarse 深度上 hs_bignet 的 G(r)/G(0) 的 RMS 偏差为 0.02–0.07, 但边缘 std 比分块 RG 高 4–9 倍);rev-KL 把幅度压到接近先验, 但空间结构完全错了(在每个粗尺度上 RMS-G ≈ 0.62–0.67,比任一 fwd-KL 行 高一个数量级;KS 边缘距离从 0.13 单调增长到 0.20)。 非临界温度的对照组 T = 2.40 在两个轴上都匹配分块 RG(深尺度 KS → 0.04, RMS-G → 0.07)。因此 V5 提供了 V4 所需的外部基准: 在该架构上没有任何流在 T_c 处做 Wilson 风格的 RG, 训练目标决定了在哪个轴上崩溃。

动机

在传统物理中,当系统处于临界相变时,缩放视角(粗粒度化)不会改变物理。 如果一个归一化流真的学到了 Ising 模型的物理,则其网络的中间层应反映出这一点: 深层应施加的数学变换应趋同。

这是 RG 不动点特征。我们设计一个探针,在受控的标准高斯输入下测量 训练好的 MERA 流的逐尺度 block 变换随深度如何演化。

如果 L=32 T_c 流真的内化了临界点的尺度不变物理,则其深层 scale-block 应收敛到同一函数形式(相邻尺度 MSE 下降并平台)。非临界流没有尺度不变性, 不应表现出这种收敛。

[V3 关于方法论前提的注释] 上述预言是必要条件但非充分:相邻 MSE → 0 既可能是因为两个 block 实现了同一非平凡的尺度不变映射(预期解读),也可能 是因为两个 block 都接近恒等(平凡)。下文 V3 利用 per-block 恒等残差 E[(f_s(z) − z)^2] 来打破这一退化。本工作探测的所有流都没有通过 "低相邻 MSE 且高恒等残差"的联合检验;rev-KL 流走的是平凡路径。

方法

第 1 步:隔离功能 block

比较的是 函数(神经网络 block)本身,而不是最终生成的图像。

对于 L=32,MERA 架构有

depth = log2(L) * nrepeat * 2 = 5 * 1 * 2 = 10

个 RNVP 模块,组织为 5 个物理粗粒度尺度(每个尺度一个 offset-0 + 一个 offset-1 mask)。 我们把每相邻两个 RNVP 模块组成一个 scale-block f_s,得到要比较的 5 个变换:

f_1, f_2, f_3, f_4, f_5

每个 block 内部含 s(·) 与 t(·) 子网络(nlayers 个耦合层 × 每个网络 nmlp 个 MLP 隐层)。

探针把每个 block 应用在 逆向方向(潜变量 → 物理变量),与 MERA 的采样路径一致。

第 2 步:标准化探针 batch

不同层操作的潜变量边缘尺度可能漂移,所以用原始数据作输入并不公平。我们采用受控探针:

  • 抽样 Z ~ N(0, I),形状为 (N, 1, 2, 2),N = 10000
  • 独立地把 Z 送过每个 scale-block(绕开 MERA 的空间 dispatch / collect, 因为 block 本身就是 2×2 patch 上的纯函数)

第 3 步:函数距离 MSE

定义

O_s = f_s(Z)               # 原始 block 输出
O_s_norm = (O_s - mean(O_s)) / std(O_s)
                           # batch 内逐元素 z-标准化

z-标准化剥除了平凡的逐 block 比例因子(若 block 3 乘以 2 而 block 4 乘以 0.5, 那不算真正的功能差异;我们关心 形状,不是比例)。

在 z-标准化输出上计算相邻尺度 MSE:

MSE(O_s, O_{s+1}) = mean[ (O_s_norm - O_{s+1}_norm)^2 ]
                 for s = 1..4

第 4 步:预期特征

区域 预期 原因
浅层尺度(f_1 → f_2) MSE 高 第一个 scale-block 把先验转为主导阶场结构;"容易"的非高斯化主要发生在这里,所以这一函数本质上不同于其他
T_c 深层尺度(f_3 → f_4, f_4 → f_5) MSE 低且平台 RG 不动点特征 —— 各尺度上重复同一函数
非临界(T=2.15 或 T=2.4) 无平台 系统有限相关长度,无尺度不变,各 block 不应趋同

[V4/V5 关于探针输入范围的注释] 第 1–3 步把每个 f_s 视为 一个函数 R⁴ → R⁴,并在 (N, 1, 2, 2) 标准高斯 patch 上求值。 这是一个 函数属性探针,不是生产输入探针。在生产正向 pass 中, f_s 接收的是由 dispatch 模式在尺度 s 上从 慢模场中切出的 patch; 据 V5,该场的 std ≈ 3.5 → 6–29(fwd-KL)或 3.5 → 1(rev-KL), 在任何中间尺度都不是 N(0, I),只有到达逆向最深的潜端时才是。 原始探针的"深层 MSE 低 = rev-KL 学到了不动点"的读法因此只是 "patch 上 N(0, I)"的陈述;V4 与 V5(保留粗粒度场探针) 才是真正检验生产慢模是否尺度不变。详细说明见下文鲁棒性章节的 "探针输入范围"小节。

解读

特征与方法论章节中"T_c 时深层 MSE 平台"的简单预言不相符。 实际的 T_c 与 T=2.40 模式 恰好相反:

  • T = 2.40(无序):MSE 在深层显著下降(0.34 → 0.15)。 最深的 scale-block 在探针上 几乎相同地 作用 —— 这是收敛到 平凡高斯不动点的特征。 非临界时相关长度短(ξ ≈ 10 格点,< L/2),最粗 MERA 尺度上场已基本去相关, 流没什么非平凡工作可做。

  • T = 2.269(T_c):MSE 在深层保持 高位(1.92, 1.92)。最深的 scale-block 在功能上仍不同。 T_c 时 ξ → ∞ 意味着不存在"超过该尺度后场不相关"的尺度 —— 每个尺度都承载真正的临界结构,流必须在每个尺度上做非平凡工作以处理长程相关。 第二个 T_c 流(hs_bignet,ep 9500)在最深一对的高值上与之相符到 3%(1.98 vs 1.92), 所以这是真实的 T_c 特征,而非单条轨迹的伪影 —— 见下方 鲁棒性检查。 (V3 更新:这条 fwd-KL 读法是经得起检验的 —— V3 在 f_3、f_4 上的残差为 2.6–15.4,确认 fwd-KL 的深层 block 做的是真正的非恒等工作。)

  • T = 2.15(有序):非单调,MSE 振荡 0.96 → 1.74 → 0.52 → 0.79。 也没有干净的平凡不动点平台。有序相有长程序(被有限 L 截断的相关长度), 深尺度仍能看到结构,但结构比 T_c 处简单,因而 MSE 取中间值, 既不像高温的平台,也不像 T_c 的发散。

这是 逆 RG 特征,而非我们假设所预言的"具有相同 block 的 RG 不动点"图像。 两种解读得到同样的物理结论(临界点在质上不同于非临界),只是数值特征相反:

方法论预言 观察结果
T_c 深层 MSE 低 / 平台 深层 MSE 高
非 T_c(T=2.40) 各深度都有非平凡 block 深层 MSE 低

最深一对的 MSE —— f_4 → f_5,最粗物理尺度,最接近潜在先验 —— 在两次运行中复现到 3%(1.92 vs 1.98),并比 T = 2.40(0.15)高一个数量级, 比 T = 2.15(0.79)高约 2.5 倍。这是稳健的 T_c 特征:在最靠近先验的尺度上, 两条 T_c 流都拒绝向平凡的恒等式映射收敛,而无序相流则锐利地收敛(最后两对 0.34 → 0.15)。

浅层对(f_1 → f_4)在两条 T_c 运行间差异显著。可能原因:

  • 两次训练处于损失轨迹的不同位置(16000 vs 9500 ep)。浅尺度承担大部分"容易"的 非高斯化,该处损失景观相对平坦,有许多近简并解 —— 不同初始种子与优化器历史在容易的模式中找到不同路线。
  • z-标准化去除了振幅,留下形状;但浅尺度的形状由 HS 场的残余局部结构驱动, 两条流可以以不同方式编码这些结构,仍能匹配同一目标边缘分布。

最深一对看到的是临界性的 定义性 特征(ξ → ∞)的长程结构,因而没有这种"容易简并"的逃逸 —— 两条流都被迫在最粗尺度上做非平凡工作,MSE 落到同一高位。

要点:f_4 → f_5 MSE 是从该探针抽出的最干净的单数字 T_c 见证。 四对的整体 形状 不是稳健指纹,但最粗一对的 数值 是。

前向 KL 族(hs_dataDriven, hs_bignet, bridge)是与预言相违的一组; bridge 运行(对桥域样本上加权 MLE)在整个扫描中最深一对 MSE 最高(2.21)。

重新解读:该探针区分的是训练目标,而非相

[V3 已修正] 本小节的"目标指纹"读法在 描述层面 仍正确 —— rev-KL 和 fwd-KL 流在 T_c 处确实产生质上不同的 per-block 行为。 但下文给出的机制解释("rev-KL 最粗 block 无事可做,塌到一个共同的恒等式 类映射")是 V3 直接验证的:那些 block 的确接近恒等。上一节"这构成 RG 不动点" 的主张是 V3 推翻的。把下文的机制读法当作对 优化器做了什么 的描述, 而不是已学到 RG 不动点的证据。

把原始的四流基线面板与方法面板放在一起,最干净的数据摘要是:

  • "深层 MSE → 0"的特征是逆向 KL 训练的属性,而不是 T_c 本身。 两条 rev-KL 流即便在 T_c(场最相关之处)也把最粗 scale-block 塌到同一映射。

  • "深层 MSE → ~2"的特征是前向 KL 训练的属性,也不(只)是 T_c。 hs_bignet 与 bridge 都坐在这一深层 MSE 高位的平台上。

  • 非临界的前向 KL 流(T = 2.15、T = 2.40)在最深一对上并不保持 MSE ≈ 2 —— T = 2.40 降到 0.15。所以"前向 KL 训练 + T_c"才会把深层 MSE 推高。 前向 KL + 非临界让深层尺度变平凡;rev-KL + T_c 也把它们变平凡(相同)。

机制读法:

  • 逆向 KL 从 q 中抽样并匹配能量来训练流。优化器看到每个 scale-block 对自身流采样的能量的贡献。最粗尺度 —— 最接近潜在先验之处 —— 看到的 几乎是高斯输入(在 q-分布视角下,深 z 尚未被后续粗粒度化"推远")。 一旦流用浅层 block 拟合了主体类高斯结构,最粗 block 就"无事可做", 塌到一个共同的恒等式类映射。T_c 上最干净的 rev-KL 解恰好就是 "最深尺度上功能相同"的那种。

  • 前向 KL 通过给数据样本打分(-log q(x_data))训练。优化器必须在 每个尺度上解释 真实 的 HS 场配置,包括承载 T_c 临界相关的长波模式。 最粗尺度看到最长程的场结构,必须每尺度做非平凡工作;不能塌到一个共同形式, 否则会破坏长程拟合。因此深层 MSE 高。

  • 混合目标(jsLoss、phase2)混合两种压力,落在中间。

回过头看,该探针其实是 T_c 处的训练目标指纹,而不是相指示。 最初的四流基线面板恰好是两条前向 KL T_c 流对一条前向 KL 非临界流 —— 所以它只捕捉到了前向 KL 特有的 T_c 抬升。方法面板才揭示完整的二维结构 (目标 × 温度)。

为何我们的假设在这里反转

[V3 注释] 回顾原报告:"fwd-KL 反转我们假设"的框架是基于 rev-KL 流产出预言中的 MSE ≈ 0。V3 表明 "MSE ≈ 0" 是近似恒等的平凡性, 所以 rev-KL 与 fwd-KL 都没有处于学到的 RG 不动点。 下文反转语言应读作"fwd-KL 深层 block 做非平凡工作,rev-KL 深层 block 几乎什么都不做", 而不是"假设在一个方向上成立,在另一方向上不成立"。

我们的假设默认流 显式 学到一个尺度不变不动点映射并反复施加。 那种情况会发生在 权重绑定(-weightTying,所有尺度共享参数)下。 这些流的 weightTying = False,所以每个尺度有自己的参数,可在该尺度 上选取任意所需的变换。

无权重绑定时,临界特征翻转:临界流 需要 在不同尺度上使用不同变换 (因为 T_c 涨落跨所有尺度),而非临界流可让深尺度变平凡(因为场在 ξ 之外已去相关)。

注意事项与可复现性

  1. z-标准化移除尺度信息。 若两个 block 仅在全局重标度上不同, 则它们在 z-标准化输出上 MSE = 0。这是有意的 —— 我们关心形状而非振幅 —— 但也意味探针对振幅差异是盲的。若 T_c 处深层 block 主要在形状上不同 (这里确实是这样),探针能看到。

  2. 2×2 patch 是自然单位。 MERA 的 RNVP 模块通过 kernelShape 参数在 2×2 patch 上工作; 在不同 patch 大小上探测会与模块训练时实际看到的不一致。

  3. N(0, 1) 探针 vs 实际 scale-block 输入。 生产中深层 scale-block 看到的是 浅层 scale-block 的输出,而非纯噪声。探针问的是"如果 block s 收到标准化噪声, 它会做什么?" —— 这是受控压力测试,而非忠实再现。其解读是"在同一受控输入上 它们是否做同样的事",这是最干净的功能距离测量。

  4. -weightTying 实验会是最强的后续:在 T_c 训练一条 L=32 流加权重绑定先验 并重新探测。权重在尺度间共享时,相邻 MSE 在每对上构造性地塌到 ~0 (因为函数字面相同) —— 这给出一个完整性校验底线,并检验权重绑定在 T_c 是否真的有帮助。

  5. L=8 / L=16 控制 —— 在更小 L 上重复同样探针,看深层 MSE 响应如何随系统大小标度。 若 T_c 时深层尺度的发散是真实的临界性特征(而非架构特有),则它应随 L 增大。

  6. 训练进度敏感性。 hs_bignet 是在 ep 9500 处探测的(对 hs_dataDriven 是 ep 16000), 所以浅对 MSE 值反映的是收敛尚不充分的状态。在匹配 epoch (例如取两者最新公共 checkpoint)上重复会让跨运行比较更锐利。 在此 epoch 失配下最深一对已经一致到 3%,说明最粗 scale-block 在训练早期就被锁定。

鲁棒性检查(V1 / V2 / V3)—— 以及它们带来的重大重新解读

跨方法分析之后,我们在最具信息量的流子集上运行了三个鲁棒性检查 (analyzers/rg_fixed_point_robustness.py,输出:rg_fixed_point_robustness.csv + 三张 PNG)。 两个检查确认了原始定性模式;第三个 推翻了"逆向 KL 满足我们假设"的主要读法, 表明那只是一个数值平凡性,而不是学到的尺度不变。

探针输入范围(V1 / V2 / V3 究竟测的是什么)

V1、V2、V3 共享原始探针的几何:输入是形状 (N, 1, 2, 2) 的 z ~ N(0, I) —— 每个 batch 元素一个 2×2 patch —— 且每个 scale-block 的 RNVP 直接通过 layer.inverse(z) 施加。dispatch / collect 管线完全被绕开。 因此这些探针把每个 scale-block 测为 R⁴ → R⁴ 函数在标准高斯 patch 上的行为, 而不是它在生产正向 / 逆向 pass 中对完整 L × L 场的作用。

在生产中:

  • 正向方向上,scale-block 接收的 2×2 patch 是由 dispatch 模式 从该尺度的慢模场中切出。据 V5,慢模场的 std ≈ 3.5(输入) → 在中间尺度上对 fwd-KL 增长至 std ≈ 6–29,或对 rev-KL 缩小至 std ≈ 1。 在任何中间尺度都不是 N(0, I)。
  • 逆向方向上,scale-block 接收的是潜在端:最深尺度上对训练良好的流 确实接近 N(0, I);较浅尺度上它是下一更深 block 产生的中间分布。

对下表数值的含义:

  • "在 N(0, I) 上近似恒等"(V3 对 rev-KL f_4、f_5 的发现)是 函数属性断言。 对 逆向 方向上的 f_5 是有生产相关性的 —— f_5 在采样时确实 接收潜在 N(0, I),所以"在潜端近似恒等"匹配它实际做的事。
  • 对 正向 方向任何 block 没有生产相关性(慢模 std ≠ 1), 对逆向方向上较浅的 f_1..f_4 也只是弱相关(f_5 跑完后它们的输入已不再是 N(0, I))。
  • "在同一 z 上 f_s 与 f_{s+1} 之间的相邻 MSE"(V1 / V2 发现)也是函数属性陈述: 它告诉我们两条 RNVP 在来自 N(0, I) 的共同 2×2 patch 上如何比较, 而不是它们组合后生产正向 / 逆向场的行为。

V4(在真实 HS 样本上的数据正向方向,限制于保留粗粒度子格点)提供了 互补的生产输入视角。把 V1–V3 当作 RNVP 函数测试;把 V4 / V5 当作生产场测试。

V2b —— 带 MERA 槽几何的链式输入(3 新 + 1 保留粗粒度)

  • patch 位置 (0, 1)、(1, 0)、(1, 1) ← 新鲜的 N(0, I) 抽样

V4 —— 数据正向方向,仅保留粗粒度子格点

V1–V3 共享原始探针的"逆向方向、孤立 block"设置:每个 scale-block 喂入 z ~ N(0, I) 并在 inverse 模式下作用于 (N, 1, 2, 2) patch。 对 RG 指纹来说这是错的方向 —— 推理时流在正向(分析)方向上处理 样本, 按 scale-block 一步步操作,索引模式同时粗粒度化。V4 复用同样 6 条流 (两条非临界对照、T_c hs_dataDriven、T_c hs_bignet、T_c sym_bignet、 T_c STL pathgrad_bignet_long_ext),并在真实路径上跑诊断:

x ~ p_HS  →  f_1.forward  → y_1  →  f_2.forward  → y_2  → … → y_S
                (最精细)                                    (潜在)

其中 f_s 是第 s 个 scale-block(layerList[2(s−1)..2s−1]), y_s 是经过 s 个粗粒度 scale-block 后的场。

保留粗粒度限制(V4 修正)。 MERA 正向方向上 s 个 scale-block 之后, 只有跨度 2^s 子格点上的位置承载流入下一 scale-block 的慢模。 其余 (1 − 1/4^s) 个位置是"冻结潜在":优化器把它们推向 N(0, 1), 而且任何更深 block 都不会再读它们。在完整 L × L y_s 上对矩、G(r)、 KS、W1 等做平均,会以 4^s 倍稀释慢模信号,并被冻结潜在位置的"地板" 所主导(例如 L=32、s=5 时,1024 个位置中只有 1 个是慢模)。因此 V4 限制到

y_s_coarse = y_s[..., ::2^s, ::2^s]      # shape (B, 1, L/2^s, L/2^s)

并只在这个慢模子场上计算各统计量。 (V4 的前一版本在所有 L² 位置上平均,现已撤回 —— 它在最深尺度上报告的 rev-KL "std ≈ 1.09、kurt ≈ 0" 实际上是 1023 个冻结位置的潜在地板, 而非保留粗粒度信号。)

V4 在保留粗粒度子格点上测什么。 在真实 RG 不动点上,慢模在相邻尺度之间 应分布上自相似(每个尺度都以其自身粗粒度单位测量)。对每相邻对计算:

  • 在标准化边缘 (y_coarse − μ)/σ 上的 KS / W1
  • 归一化轴向两点函数 G_s(r) / G_s(0) 的 RMS 偏差, 定义在 L_s × L_s 粗格点上,r = 1..min(L_s, L_{s+1})/2

慢模上的恒等平凡性不构成混淆:一个近似恒等 block 作用在非平凡慢模分布上 会留下非平凡分布,所以相邻尺度的一致仍然要求流真正复现了粗粒度统计。

V5 —— Wilson–Kadanoff 分块 RG 真值

V4 测的是保留粗粒度子格点上 MERA 的正向级联,但没有外部参考来说明 慢模级联应该长什么样。V5 通过在 相同的 HS 场输入上跑经典 Wilson–Kadanoff 分块平均级联,并在每个尺度上把 MERA 子采样的 y_s_coarse 与之进行 分布间比较,来提供这一参考。

分块 RG 级联。 对每个 batch x ~ p_HS 计算

x_0 = x                                          (B, 1, L,   L)
x_s = AvgPool2d(2)(x_{s−1})                       (B, 1, L/2^s, L/2^s)

即尺度 s 上的每个粗像素是原始 HS 场上一个 2^s × 2^s 块的无权平均。 这是教科书上的块自旋变换(在 HS 对偶变量的连续场极限下),不含任何学习。 在 T_c 处,分块平均场在 2D Ising 普适类下流向一个非高斯的不动点分布, 其特征为幂律两点相关与双峰边缘 —— 不是流向高斯。

跨比较。 对每个尺度 s = 0..5,在 同一输入 batch 上(因此二者是配对的) 评估标准化 MERA 子采样慢模 (y_s_coarse − μ)/σ 与标准化分块 RG (x_s − μ)/σ 之间的三种距离:

  • v5_ks —— 标准化边缘上的 KS 距离

  • v5_rms_g —— 两者间 G_s(r)/G_s(0) 的 RMS 偏差

重新解读

原报告的结论是 逆向 KL 流满足我们的假设(T_c 处深层 block 在功能上一致)。 V3 表明这一结论在其自身条件下是错的:深层 block 不是"同一非平凡的尺度不变变换", 而是"近似恒等"。仅靠 z-标准化输出上的 MSE 在构造上就无法区分这两种情况。

数据 支持 的结论:

  • T_c 处的前向 KL 流在每个 MERA 尺度上都做真正的工作。 它们的 per-block 恒等残差在 f_3、f_4、f_5 上都很大 (hs_dataDriven 在 f_4 上为 15.4,hs_bignet 在 f_3 上为 4.9), 且 f_4 与 f_5 间的相邻 MSE 捕捉的是真正的功能差异,而不是冗余。 这与"前向 KL 必须在所有尺度上解释 HS 场数据的结构"的物理图像一致。
  • T_c 处的逆向 KL 流把最粗尺度塌向恒等。 浅 block 拟合主体后,优化器的压力把 f_4、f_5 推向近似恒等。 最粗 block 实现的"函数"不是"普适 RG 变换";而是"什么都不做"。
  • 跨方法面板暴露的"前向 KL / 逆向 KL 分裂"因此是"非平凡深层 block" 与"平凡(恒等)深层 block"的分裂,而不是两种不同的非平凡 RG 不动点实现。

原方法论框架"若深层 block 行为相同,则是 RG 不动点"是必要而非充分。 要把不动点映射与平凡恒等区分开,必须检查 V3 的恒等残差。 缺了它,"相邻 MSE 低"是有歧义的。

原始框架仍需满足的条件以使其可检验

该架构上一个真正意义上的 RG 不动点读法需要一条流:

  • f_4 与 f_5 有 大 恒等残差(它们做非平凡工作),并且
  • 它们在同一输入上的相邻 MSE 小(它们的非平凡工作是 同一 变换)。

扫描中没有任何流同时满足两个条件。最接近的是 T_c hs_bignet (f_3、f_4 残差大;f_5 中等;但其 f_4 → f_5 MSE = 1.98, 即非平凡 block 之间不一致)。所以 目前所有流都不可能处于方法论严格意义下的 RG 不动点。

鲁棒性之后的可接受结论

  • T_c 处前向 KL 在每个 MERA 尺度上做实质工作;逆向 KL 不做。 这本身就是对两种训练目标的有用刻画。
  • 跨方法面板仍然干净地区分目标(rev-KL → 近似恒等的深层 block; fwd-KL → 非平凡的深层 block)。
  • MERA 尺度分组与绕开 dispatch 的功能探针定义良好且可复现。
  • (来自修正后的 V4,保留粗粒度) 逆向 KL 流在慢模子格点上 std 单调收缩 3.51 → 0.94,峰度 → 0,中间粗尺度上有 负 最近邻相关。 慢模被抹除(塌缩到 N(0, 1) + 反相关噪声),而不是被粗粒度化。 分块 RG 真值(V5)预言 std → 2.46,双峰 kurt ≈ −1.84。
  • (来自修正后的 V4) 前向 KL 慢模膨胀(T_c hs_dataDriven: y_3 处 std 3.51 → 28.94),之后部分回落,从未达到形状自相似 (相邻标准化 KS 在每个粗对上都 ≥ 0.05),G(1)/G(0) 保持为正(物理), 但没有任何流的粗级联真正匹配分块 RG。 该架构上没有任何流在做 Wilson 风格的 RG, 原始 V4 的"rev-KL 在潜端平凡地接近尺度不变"的框架是 全 L² 平均的产物,不是慢模。
  • (来自 V5,与同输入上的 Wilson–Kadanoff 分块 RG 跨比较) 训练目标决定"真正粗粒度化"的哪个轴上崩溃:fwd-KL 在 coarse 深度上保留 G(r) (hs_bignet 在 s = 2–3 上 RMS-G ≈ 0.02–0.07)但把边缘方差比分块 RG 高 4–9 倍; rev-KL 把边缘保持得小但完全破坏 G(r)(每个尺度上 RMS-G ≈ 0.62–0.67, 比任何 fwd-KL 行高一个数量级)。两轴分解(KS 看边缘,RMS-G 看空间结构) 使失败成为定量的,而非定性的。
